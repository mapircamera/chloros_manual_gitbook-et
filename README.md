# Alustamine

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>Chloros on [MAPIR](https://www.mapir.camera) tarkvararakendus piltide ja muude andurite andmete töötlemiseks.

***

Chloros on saadaval kolmes rakendusrežiimis:

## Chloros: töölaua GUI rakendus

Eraldi aken kõigi funktsioonidega.

## [Chloros CLI: käsurealiides](CLI.md)

Käsurealiidesega pakettide töötlemine. Sobib ideaalselt automatiseerimiseks, skriptide kirjutamiseks ja keerukate töövoogude jaoks. _CLI kasutamiseks on vaja Chloros+ litsentsi._

## [Chloros API: Python SDK](api-python-sdk.md)

Programmeeritav Python liides automatiseerimiseks ja kohandatud töövoogudeks. Sobib ideaalselt uurimistööde jaoks, integreerimiseks olemasolevate Python rakendustega ja kohandatud tööriistade loomiseks. _API kasutamiseks on vaja Chloros+ litsentsi._

***

## Chloros+

Kuigi Chloros on enamiku ülesannete jaoks tasuta kasutatav, võite avastada, et soovite enamat. Siin võib kasuks tulla Chloros+ tasuline litsents. Chloros+ litsentsiga saate avada uusi funktsioone, nagu:

* **Mitmeprotsessiline töötlemine**: kiirendab oluliselt suuremate projektide pilditöötlust, töötlemisprotsessi kaudu pilte samaaegselt töödeldes.
* **GPU (CUDA) kiirendus**: kasutage tänapäeva suuremaid GPU mälu võimalusi, et veelgi kiirendada pilditöötluse torujuhet. Parimate tulemuste saavutamiseks soovitame 4 GB või rohkem VRAM-i.
* **Chloros+**[**CLI**](CLI.md)**Juurdepääs**: käivitage Chloros+ käsurealt, et automatiseerida ja integreerida oma tarkvarasse.
* **Chloros+**[**API**](api-python-sdk.md)**Juurdepääs:** käivitage Chloros+ programmilise juhtimise jaoks Python-st, võimaldades sujuva integreerimise teie uurimisprotsesside, andmete analüüsi töövoogude ja kohandatud rakendustega.
* **Mitme seadme kasutamine**: iga Chloros+ litsents võimaldab registreerida 2+ seadet. Kasutage oma MAPIR pilvekontot registreeritud seadmete haldamiseks. Lisage tugi rohkematele seadmetele, uuendades oma Chloros+ litsentsi.
* **Täiustatud tekstuuritundlik debayer-meetod:** kõrgekvaliteetne servatundlik debayer koos AI/ML müra vähendamise mudeliga, mis eemaldab peaaegu kogu debayering-müra.
* **Kohandatud multispektraalsed indeksivalemid:** sisestage kohandatud multispektraalsed indeksid Chloros rasterarvutitesse, nii töötlemiseks kui ka piltide vaatamiseks.
